## 2. 功能、数据与去向

| 场景 | 处理的信息 | 目的及去向 |
|---|---|---|
| 登录和连接 | 用户输入的用户名、密码、服务地址、连接模式 | 公网登录会向默认服务 https://dsh.ainotex.com/directory/login 请求账户对应实例；后续认证和请求发送至连接的服务器。局域网模式连接用户指定地址。 |
| AI 对话和任务 | 输入文字、选择发送的图片、会话标识、任务参数及返回的回答/工具结果 | 应用不提供或托管用户的 Agent，也不提供 AI 模型服务。Agent 与模型均由用户自行提供、部署和配置，客户端向用户配置的 Agent 服务发送请求并展示结果。用户本地部署的 Agent 若另行接入云端模型或工具，其数据接收方和处理地区取决于用户配置，不能一概声明全部在手机本地处理。 |
| 本地缓存 | 会话列表、聊天内容、统计、连接设置、登录凭据、社交令牌、语言/主题、宠物状态、资讯缓存 | 使用 SQLite 和偏好存储提供恢复会话和界面设置功能。当前代码不能证明凭据或数据库应用层加密。 |
| 好友与动态 | 昵称、头像、社交标识、好友关系、消息、发布内容及提示次数统计 | 发送至默认域名的 /social 服务，支持好友交流、动态和统计展示；主动发送或发布的信息会按对应功能向接收者展示，具体可见范围需核对服务端。即使 Agent 使用自定义地址，社交服务仍为固定域名。 |
| 意见反馈 | 反馈类别、用户填写的描述和可选联系方式；已提供的认证信息 | 用户提交时发送至 https://dsh.ainotex.com/social/feedback，以处理问题和反馈。不要填写无关敏感信息。 |
| AI 资讯 | 网络请求所必需的信息，如服务器可见的来源 IP | 从 https://dsh.ainotex.com/app/content/ai/ 加载资讯和 Agent 信息并本地缓存；服务端日志采集项和期限待核实。 |
| 局域网发现 | 本地网络中的服务名称、主机地址与端口 | 通过 mDNS 发现服务，失败时会扫描手机所在 /24 子网的服务端口；不是地理位置定位。 |

## 3. 权限和自主选择

当前鸿蒙模块声明 INTERNET 和 READ_MEDIA。网络用于连接服务；媒体读取用于用户选择图片并发送至对话或作为头像。拒绝媒体访问会影响相应图片功能。客户端还保留调用系统拍照的入口，其鸿蒙实际支持情况及最终合并包权限应在真机验证后准确披露，不应虚构已支持的权限。

本次扫描未发现客户端调用通讯录、精确定位、广告标识符或麦克风采集功能；这不是对全部依赖及服务器行为的完整审计结论。

## 4. 第三方组件与服务

客户端使用 Flutter/OpenHarmony 适配组件，包括 shared_preferences（设置和凭据）、sqflite（聊天缓存）、path_provider（应用目录）、image_picker（选择图片）、package_info_plus（应用版本）、http/web_socket_channel（通信）和 multicast_dns（局域网发现）。组件版本与固定 Git 提交见 pubspec.yaml、pubspec.lock。库依赖不等于数据独立传输给其作者；对具体鸿蒙原生实现仍需检查，不能仅凭依赖名承诺“不收集”。

本应用不提供用户的 Agent 或 AI 模型服务；用户自行配置的模型及 Agent 工具服务应与应用运营者提供的固定服务区分说明。应用固定服务使用的托管/CDN/日志服务主体、接收数据、目的、地区及政策链接仍需按实际部署核对，不因模型由用户提供而免去披露。

## 5. 信息保存及安全

本地信息保存在应用存储中。退出登录的现有代码删除 authUser、authPass、serverUrl，但不会清空全部聊天缓存和 socialToken，因此“退出即全部删除”不成立。卸载/系统清除应用数据的效果取决于系统行为，云端记录不会因此自动删除。

根据开发者于 2026-09-10 的确认，dsh.ainotex.com 对应的应用自有服务部署在中国大陆（深圳）。用户自行配置的 Agent 和模型服务不受此部署地点描述涵盖。CDN、代理、备份和其他第三方处理地区尚未核实，因此该确认不等于“全部数据不出境”。日志、社交、反馈等服务端数据及备份保存期限、删除执行周期仍待确认，不擅自填写天数。

公网默认地址使用 HTTPS；局域网允许 HTTP，不能承诺所有链路均加密。当前凭据保存在普通偏好存储中，应迁移到系统安全存储并验证账号切换清理/隔离后，再邀请朋友使用真实账号和敏感数据。

## 6. 访问、更正、删除和注销

用户可在会话和社交界面查看相关内容、修改昵称或头像，删除自己发布的动态、移除好友。账户注销、聊天/社交数据完整删除和备份清理流程尚需确认；不得将“退出登录”描述为注销。拟提供邮箱申请渠道，但需确认负责处理的人、身份核验方式和可执行的回复及删除期限后，再形成正式承诺。
