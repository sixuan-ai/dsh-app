# 电脑连接器实现与验收

2026-11-03，xHarness 2.2.0+137。实现范围为 Linux 电脑连接器、Android 客户端配对入口，以及既有 HTTPS 公网网关的可选设备路由。

## 已实现

- 独立 TLS 网关：2 分钟、一次性二维码；独立设备凭据；电脑仅保存加盐 PBKDF2 散列；设备撤销同时关闭已有 WebSocket。
- Linux 安装、重复安装更新、诊断、二维码、设备管理、卸载与恢复。已有 DSH 不重启，原工作区不复制、不删除。运行文件复制到持久目录。
- 桌面管理页：仅随机回环端口，一次性启动凭据换取 HttpOnly / SameSite 会话，30 分钟过期；校验 Host 和写操作 Origin。
- 公网网关：账号校验、电脑归属保护、限制 Tailscale IPv4 与连接器端口、校验证书指纹与桌面注册密钥持有证明；HTTP / WS 统一保留电脑路径前缀。
- 网关使用独立散列导出文件，不能读取现有明文账号目录。目录变更监视与 60 秒定时核对，删除账号后阻止新的公网请求。
- 手机拍照/相册二维码识别、粘贴链接/JSON、电脑身份确认、系统安全存储、局域网优先与已登记公网回退。新设备凭据不发送给官网账号服务。
- 同电脑路由共用电脑 UUID 缓存范围，切换保留当前任务。退出/忘记过程中取消迟到的探测和连接响应；忘记配对可恢复旧路由。
- 原始 DSH 授权 Cookie 仅在内部认证桥使用，不返回给设备，HTTP 和 WS 握手均过滤 Set-Cookie。
- 更新 README、App 内连接指南与运维说明；旧 frp / 域名步骤移入历史记录。

## 实际部署

电脑上原 `dsh-desktop.service`（回环 18395）和 `dsh-web-auth.service`（3081）继续运行；新增 `xharness-connector.service`（HTTPS 3082）及回环认证桥 3083。默认目录 `~/.local/share/xharness-connector`，应用菜单新增「xHarness 电脑连接器」。

既有 `dsh.sixuanai.com` 新增 `/connector/` 路由，hub 仅监听回环 3087。电脑登记归属经过现有绑定账号校验，以及网关对实际电脑的证书、注册密钥持有证明检查。原网站 `/` 与账号目录服务保留。网关 nginx 配置在修改前备份，`nginx -t` 后 reload。

部署后 doctor：认证桥 HTTP 200、TLS 身份与公网身份检查全部通过；原生 DSH 未认证返回 401 属于预期的原生访问保护。

## 范围与未验收项

- 当前只交付 Linux + systemd 用户会话安装器。Windows/macOS 安装器与 iOS 配对未验收。
- 新 Android APK 没有覆盖手机原安装，也未改其已保存的账号/路由。相机拍摄二维码的真机端到端体验仍需在安装此版本后验收；已完成二维码图片解码、真实 Dart HTTP/WS 协议及安全存储单元验证。
- 一次只保存一台配对电脑；二维码首次领取需同一网络。局域网地址变化需要重新配对，尚未增加新连接器的 mDNS 自动更新地址。
- 公网首次部署和 Tailscale 入网、ACL 授权仍由管理员完成。手机不需要 VPN，但不能宣传为任意用户完全自动接入公网。
- 账号改密/删除由导出同步生效；账号目录改动不直接关闭已经打开的 WS。立即撤销手机须使用电脑设备撤销功能。
- 手机「忘记」和卸载连接器不删除远端注册记录或工作区。连接器卸载保留配置以便修复与恢复，具体回退见使用文档。
- 公网是手机到网关 TLS、网关到电脑固定证书 TLS，两段加密；网关可见流量，不是端到端加密。

## 2.2.1 多电脑修复

针对配对 x-26 后原 OMEN 入口消失的问题，App 将单条安全存储升级为 `xharness.paired.computers.v2` 电脑列表，按电脑 UUID 保管独立设备凭据和当前选择；兼容读取 2.2.0 的单条记录，首次修改时写入新版并移除旧键。添加、切换或忘记一台电脑不会删除其他电脑，注销账户则清除该手机保存的电脑密钥。重新登录同一账户保留已配对电脑，更换账户时清理旧配对。

连接中心同时显示“已配对电脑”和“账号电脑”。升级启动会重新加载原账户缓存的电脑列表，因此保留现有 x-26 配对的同时恢复 OMEN 账号入口。切回 OMEN 时只向目录与该电脑发送原账户凭据；不会拿 x-26 的设备密钥去登录 OMEN。切回 x-26 时使用它自己的设备凭据。各电脑按 UUID 使用独立缓存范围，过期连接响应不能改写新的电脑选择。

验证：静态检查通过；全量 241 项通过，另一个按环境变量显式开启的真实服务测试在全量执行中跳过，已单独运行并通过。新增回归覆盖旧 x-26 记录迁移、并发保存两台电脑、重新配对不重复、移除一台仍保留另一台、启动恢复原 OMEN 账号入口、账号凭据与设备凭据分离、缓存范围独立，以及连接中心同时展示和选择两类电脑。

真实服务测试按“x-26 → 原 OMEN 账号 → 已配对 OMEN → x-26”往返执行，比较了返回后的会话身份集合和持久化电脑列表。使用临时测试设备，实际用户手机配对不变；测试设备已全部撤销，临时凭据文件已删除。该版本不要求用户重新配对已保存的 x-26。历史上已经被 2.2.0 覆盖且不在账号缓存中的其他二维码凭据无法恢复，需要重新配对；原账号电脑入口不受这个限制。
