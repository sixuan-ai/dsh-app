# xHarness 2.5.3

日期：2026-11-03。Flutter build number 145，arm64 APK versionCode 2145。

## 权限切换

底部快捷菜单仅保留一个权限选择入口，过滤服务器目录和内置回退列表中的原始 `/permission` 项，避免将前缀填进输入框。底部和侧边栏共用 `showPermissionPicker`，直接提供工作区写入和完全访问选项。

选择器从当前会话 `permissions.currentValue` 投影标记当前权限。完全访问沿用二次确认；取消不发送命令，确认期间切换会话也不会向新会话发送权限切换。

## 接口修复

新版 Typert 命令接口接收顶层命名参数：

- `commands/list` 的 `payload.args`：`{agentId}`。
- `commands/execute` 的 `payload.args`：`{agentId, line, submittedAttachments: []}`。

旧实现嵌套 `request` / `args`，并使用过时的 `images` 字段，触发截图中的 `gateway/arguments-invalid`。本次修复同时恢复快捷命令目录读取和所有文字斜杠命令的执行路径。权限切换仍由 DSH 命令注册表执行并反馈结果。
