# xHarness 2.5.2

## 修复

- 工具调用和 `tool/result` 分属不同历史页时，完成结果不再丢失。按 callId 合并调用参数、成功或失败结果、图片，避免历史重放把已完成卡片降回运行中。
- 建立 `session/follow` 时比较 snapshot cursor 和本地水位；补齐历史读取与订阅注册之间完成的工具结果。
- 子代理 Host 状态立即更新列表；状态弹窗订阅 AppState，顶部选择器纳入代理和加载状态。过期请求不能覆盖另一个会话或连接，刷新失败保留已有目录。
- 模型目录使用 Host 的 `session.modelCatalog`，当前模型使用会话 `modelSelection.next`，未配置时回退到目录默认值。高水位投影优先，电脑端的模型与推理强度选择实时同步。
- 会话打开、断线恢复时加载模型；请求绑定会话与 API 实例并校验请求代次。目录加载失败保留已知选择，模型弹窗实时读取最新目录。

工具卡片依据完成结果收尾，不以单次脚本退出推断整个 Agent 会话已经结束。
